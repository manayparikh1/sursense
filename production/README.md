# Production files

Everything needed to build one SurSense.

## STEP/

Three printed parts, generated by `cad/enclosure.py`. STEP is the editable
source, STL is ready to slice.

- `lower_shell` — battery bay, speaker grille, USB-C cutout, four M2 bosses
- `upper_shell` — display rebate, mic port and gasket seat, bezel drive window
- `bezel` — the knurled ring that turns the encoder

Print in PLA or PETG, 0.4mm nozzle, 0.2mm layers. The bezel wants to be printed
flat so the flutes come out crisp.

Regenerate with:

    pip install cadquery
    python3 cad/enclosure.py

## gerbers/

Not generated yet. Comes from the KiCad board in `hardware/` once the layout is
routed: File, Fabrication Outputs, Gerbers.

## firmware/

Build from `firmware/` with PlatformIO:

    cd firmware && pio run

The binary lands in `firmware/.pio/build/sursense/firmware.bin`. Flash with
`pio run -t upload`.

## Assembly

1. Solder the board, positions in `docs/placement-table.png`
2. Heat-set four M2 inserts into the lower shell bosses
3. Bond the PETG lens into the upper shell rebate
4. Fit the mic gasket, 4x2 silicone O-ring, into its seat
5. Press the friction wheel onto the EC11 shaft, then fit the bezel
6. Flash over USB-C, then close the shells with four M2x6 screws
